🎯 Gerenciador de Missões

Um aplicativo desenvolvido em HTML, CSS e JavaScript puro para ajudar no gerenciamento de missões e tarefas do dia a dia.

O projeto foi criado como parte dos estudos de JavaScript, evoluindo gradualmente desde conceitos básicos até a construção de uma aplicação completa com persistência de dados, filtros e sorteio inteligente de missões.

🚀 Funcionalidades
📌 Gerenciamento de Missões
➕ Adicionar novas missões;
✏️ Editar missões existentes;
✅ Marcar missões como concluídas;
🔄 Desfazer a conclusão de uma missão;
🗑️ Excluir missões com confirmação.
📊 Estatísticas Automáticas

O sistema atualiza automaticamente:

Total de missões;
Quantidade de missões concluídas;
Quantidade de missões pendentes.
🔍 Filtros

Visualize apenas as missões desejadas:

Todas;
Pendentes;
Concluídas.
🎲 Sorteio Inteligente
Sorteia apenas missões pendentes;
Exibe uma mensagem amigável caso não existam missões disponíveis para sorteio.
💾 Persistência de Dados
As missões são armazenadas no Local Storage do navegador;
Os dados permanecem salvos mesmo após fechar ou atualizar a página.
⌨️ Experiência do Usuário
Adição de missões utilizando a tecla Enter;
Campo de texto recebe foco automaticamente após adicionar uma missão;
Confirmação antes da exclusão.
